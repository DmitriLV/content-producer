# Content generator

Приложение на Python для генерации изображений, инфографик и текстов через OpenAI и GigaChat.

## Возможности

- Ввод текстового запроса прямо в терминале (диалоговый режим) или как аргумент командной строки (одноразовый режим).
- **Режим изображения** — генерация картинок/инфографик по вашему запросу через OpenAI (`OPENAI_API_KEY`, `OPENAI_MODEL` из `.env`).
- **Режим статьи** — GigaChat (`GIGACHAT_CREDENTIALS` из `.env`) пишет короткий текст на русском на тему ЗОЖ, питания, полезных нутриентов и витаминов; текст сохраняется в `output/`, а затем на его основе OpenAI сразу создаёт инфографику (тоже в `output/`).
- Автоматическое сохранение результатов в отдельную папку `output/` с именем файла на основе даты и запроса/темы.
- Системное уведомление (toast) — отдельно о готовности текста и отдельно о готовности визуализации.

## Установка

Зависимости уже установлены в виртуальное окружение `.venv` в этой папке. Если нужно пересоздать окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

## Настройка (.env)

В файле `.env` уже используются переменные:

```
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-image-2      # необязательно, по умолчанию gpt-image-1
OPENAI_BASE_URL=https://api.openai.com/v1   # необязательно

GIGACHAT_CREDENTIALS=...      # нужен только для режима статьи
GIGACHAT_SCOPE=GIGACHAT_API_PERS   # необязательно, это значение по умолчанию
GIGACHAT_MODEL=GigaChat-2          # необязательно, это значение по умолчанию
```

Режим изображений работает независимо от GigaChat — `GIGACHAT_CREDENTIALS` требуется, только когда вы используете режим статьи.

Дополнительно поддерживаются (необязательные, можно добавить в `.env`):

```
OUTPUT_DIR=output              # папка сохранения (относительно проекта или абсолютный путь)
OPENAI_IMAGE_SIZE=1024x1024    # размер по умолчанию
OPENAI_IMAGE_QUALITY=high      # качество по умолчанию: low / medium / high / auto
```

## Запуск

### Диалоговый режим (рекомендуется)

```powershell
.\.venv\Scripts\python.exe main.py
```

Приложение попросит вводить запросы один за другим. Есть два режима ввода в рамках одной сессии:

**1. Обычный запрос → изображение/инфографика напрямую (OpenAI):**

```
> инфографика: 5 привычек продуктивности
⏳ Генерирую изображение по запросу: "инфографика: 5 привычек продуктивности" ...
✅ Сохранено: C:\...\output\20260908_192141_инфографика_5_привычек_продуктивности.png
```

**2. Префикс `статья:` → текст (GigaChat) + инфографика на его основе (OpenAI):**

```
> статья: польза витамина D для иммунитета
✍️  Пишу текст по теме: "польза витамина D для иммунитета" (GigaChat) ...
✅ Текст сохранён: C:\...\output\20260908_214148_польза_витамина_D_для_иммунитета.txt
🎨 Генерирую инфографику на основе текста (OpenAI) ...
✅ Инфографика сохранена: C:\...\output\20260908_214413_польза_витамина_D_для_иммунитета.png
```

Кроме `статья:` также работают префиксы `текст:`, `article:`, `пост:`.

После готовности текста и после готовности изображения появляются отдельные системные уведомления. Для выхода введите `exit` или `выход`.

### Одноразовый режим

```powershell
# Изображение по запросу
.\.venv\Scripts\python.exe main.py "инфографика: этапы запуска стартапа"

# Текст (GigaChat) + инфографика на его основе (OpenAI)
.\.venv\Scripts\python.exe main.py --article "польза клетчатки для организма"
```

### Дополнительные параметры

```powershell
.\.venv\Scripts\python.exe main.py "постер к статье о космосе" --size 1024x1536 --quality high -n 2
```

- `--article` — включить режим статьи (GigaChat пишет текст, затем OpenAI делает инфографику). В диалоговом режиме можно также указывать это только для отдельных запросов через префикс `статья:`.
- `--size` — размер изображения (например `1024x1024`, `1024x1536`, `1536x1024`).
- `--quality` — качество (`low`, `medium`, `high`, `auto`).
- `-n / --count` — сколько изображений сгенерировать за один запрос.
- `--output-dir` — своя папка сохранения вместо `output/`.

## Веб-интерфейс (локально)

Кроме CLI есть простой локальный веб-сайт на Flask с той же функциональностью:

```powershell
.\.venv\Scripts\python.exe webapp.py
```

Затем откройте в браузере **http://127.0.0.1:5000**.

Возможности сайта:

- Поле ввода запроса/темы + галочка «Статья (GigaChat) + инфографика на её основе» (если снята — генерируется только визуализация по запросу, как в обычном режиме CLI).
- Прогресс-бар с этапами («Пишу текст (GigaChat)» → «Генерирую изображение (OpenAI)» → «Готово»). Точный процент от API получить нельзя, поэтому бар плавно заполняется по расчётному времени и не подскакивает на 100%, пока результат не готов на самом деле.
- Каждый запрос обрабатывается по одному в очереди (последовательно), чтобы не перегружать API.
- Готовые тексты и изображения выводятся прямо на странице в карточке запроса.
- Новые запросы добавляются сверху, а результаты предыдущих остаются на странице — история сохраняется в `data/history.json` и переживает перезапуск сайта.
- У каждой карточки есть кнопка «✕» — удаляет запись из истории и стирает связанные файлы (текст/картинку) из `output/`.

Сайт работает только локально (`127.0.0.1`) и не публикуется наружу. Изображения раздаются напрямую из папки `output/` через `/media/<имя файла>`.

## Структура проекта

```
main.py                 # точка входа CLI
webapp.py                # точка входа веб-интерфейса (Flask)
imagegen/
  cli.py                  # интерактивный/одноразовый CLI-режим (изображения + статьи)
  config.py               # загрузка .env и настроек (OpenAI + GigaChat)
  openai_client.py         # обёртка над OpenAI Images API
  gigachat_client.py       # обёртка над GigaChat API (генерация текста)
  jobs.py                  # очередь задач, фоновый воркер и прогресс для веб-интерфейса
  web.py                   # Flask-приложение и API-эндпоинты
  notifier.py              # системные уведомления (toast) для CLI
  utils.py                 # безопасные имена файлов
templates/index.html      # HTML-страница веб-интерфейса
static/style.css, app.js  # стили и клиентская логика (форма, прогресс, карточки)
output/                  # сюда сохраняются готовые тексты (.txt) и изображения (.png)
data/history.json        # история запросов веб-интерфейса (создаётся автоматически)
```
